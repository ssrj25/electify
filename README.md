# Electify

A Web3-based decentralized voting application that explores blockchain-enabled voting with ward-based polls.

## Features

- Decentralized voting workflow
- Web3 and MetaMask integration
- Ward-based poll organization
- Ethereum and Polygon support

## Tech Stack

- React.js
- JavaScript
- Web3.js
- Ethereum / Polygon
- MetaMask
- Ganache
- Truffle
- Axios
