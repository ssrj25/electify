# Electify: Decentralized Online Voting Application

Electify is a Web3-based voting application that explores decentralized voting using blockchain technology. It provides a React interface where users connect a Web3 wallet, select a candidate, and submit their vote as a blockchain transaction.

## What It Does

The application organizes voting by electoral locations and connects the frontend to smart-contract-based voting logic. Users can connect their MetaMask wallet, view candidates, submit a vote, and receive confirmation after the transaction is completed. The project includes voting flows for locations such as Mumbai and Kolkata.

## Key Features

- Web3 wallet integration using MetaMask
- Candidate-based voting interface
- Blockchain transaction for vote submission
- Location/ward-based voting flows
- Voting result and confirmation pages
- Ethereum and Polygon development support

## Architecture

```text
Voter
  ↓
React Frontend
  ↓
MetaMask / Web3.js
  ↓
Voting Smart Contract
  ↓
Ethereum / Polygon Network
```
